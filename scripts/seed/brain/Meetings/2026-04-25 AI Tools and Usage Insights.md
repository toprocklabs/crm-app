## Notes
Important themes:

- Coatary needs scalable technical support for contractors/distributors, especially as the company expands beyond a loyal base into broader distribution.
- Flint built a product/system selection tool with Claude API support, Vercel deployment, GitHub repository, and Stripe integration direction, but the code workflow is still inefficient because he is copying code manually rather than using Claude Code.
- The product-selection tool can reduce support load by asking for job details such as square footage, location, temperature, indoor/outdoor use, and flake selection, then producing recommendations and purchase-order-style output.
- Peaceful Property Management may need a separate AI operations system: front desk support, email processing, staff role guidance, policy/procedure lookup, and second-brain integration with Notion/Slack.
- Social media automation is a near-term opportunity for Coatary and Peaceful: use existing photos, generate variants, draft recurring posts, and keep the businesses visibly active on Instagram, LinkedIn, and Facebook.
- Longer-term opportunity: if the model works, Toprock may have a repeatable small-business AI implementation offering and possibly larger enterprise opportunities through Flint's manufacturing and LG-related network.
