# Vive Website and Booking System

## Goal
Rebuild [[Vive Massage]] with a custom, AI-search-friendly website and potentially a scalable booking/scheduling system for multiple therapists.

## Status
prospect

## Notes Log
- 2026-05-07: Eddy and Justin discussed a basic custom website, hosted on Vercel or handed off as files, with a rough basic-site price around `$500`.
- 2026-05-07: Larger opportunity is a custom booking backend with individual therapist logins, availability management, Google Calendar sync, on-site customer booking, therapist notifications, and payment processing.
- 2026-05-07: Justin positioned Toprock against Squarespace/WordPress/template constraints and emphasized AI-searchability through richer service and modality content.
- 2026-05-07: Existing Toprock examples used in the pitch included The Scuba Dive custom booking flow, custom CRM/admin systems, and sport recruiting admin/check-in workflows.

## Decisions
- Separate basic website pricing from custom booking/scheduling system pricing.
- Prefer Stripe for custom checkout, while keeping Square integration possible.
- Use Vercel hosting if Toprock hosts the site and points Eddy's domain to the deployment.
- Proposal should make the scalability argument explicit: multiple therapists now, 15+ therapists or franchise/multi-location workflows later.
