## 1. Current site & costs

- Coatary runs on **WordPress** with **Elementor Pro**; the domain is on **Bluehost**.
- Plan: **drop WordPress + Elementor Pro** (kills those recurring costs) and keep paying only for the **Bluehost** domain.

## 2. The custom-build pitch

*Top Rock's value framing: a custom-coded site at template-tool prices.*

- "A boutique, crazy web-development company for the cost of what you'd normally pay for a **Wix or Squarespace**."
- Everything is **fully custom-coded**, not a standard template — "you don't get this type of stuff" from a template builder.
- Examples shown: a **character-booking website** in progress, the **Temple View** football head-coach recruiting site (a paying customer — sends players' stats/profiles to recruiting colleges, with a self-serve admin button), and the **Scuba Dive** project where they're "replacing third-party vendors and bringing it all in-house."
- Core thesis: *"Before, people built software to fit everybody. Now we build the software to fit you."* Build a system that works for Coatary, keep the engine the same behind the scenes, and **skin it to the next customer**.

## 3. Self-serve admin vs. text-for-edits

- Two ways to handle ongoing edits: Top Rock builds a back-end **admin page** Flint can use himself (like the Temple View example — upload content, auto-styled to fit), **or** Flint just **texts Austin** and edits get done fast.
- Eventually (once scaled) Top Rock wants an **agent** to handle all edits — "not quite there yet."

## 4. Pricing

- **~$300 implementation** (covers the build hours) + **~$10/mo**, including the admin system to manage everything.
- Austin's posture: as an **investor** in Coatary he doesn't need the money — "the money is a nice-to-have." It mainly has to not cost *him* money, and Justin (50/50 on Top Rock) needs his share.
- Initial costs are basically the **Claude Code license + AI/token cost** to build it; possibly some **database** spend later depending on data needs — "nothing dramatic."

## 5. Productize & go-to-market idea

*Flint and Austin riffed on turning the model into a product.*

- Once built out, they could **productize it** and create an **entity** around it (the new entity owning a percentage), then skin it for other customers.
- Austin's condition: he doesn't have time to sell it — so if **Flint connects them to buyers / handles go-to-market**, he's "all game." Flint floated chasing **~$100K/yr contracts**.
- Caveat: Top Rock is building this **after-hours** around day jobs and a couple of existing customers, so pace is realistic.
